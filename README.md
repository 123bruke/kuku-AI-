### 🌌 Immersive AI Experience

**KUKU AI** is a futuristic AI-powered web application designed with a **3D liquid-glass UI**, smooth animations, and intelligent AI interactions.

Built using **React + Vite + TailwindCSS**, the platform combines performance, aesthetics, and AI into one modern experience.
