# 🚀 KUKU AI

**KUKU AI** is a modern, immersive AI-powered web application built with **React + Vite + TailwindCSS**.  
It delivers a **3D-inspired, liquid-themed UI experience** with interactive AI features.

---

## ✨ Features

- 🤖 AI-powered assistant (Gemini API integration)
- 🌊 Liquid glass UI design (modern glassmorphism)
- 🎨 Fully responsive & animated interface
- 📂 File upload & processing
- 🌐 Multi-language support
- 📊 Dashboard-style layout
- ⚡ Fast performance using Vite
- 🌙 Dark / Light mode support

---

## 🛠️ Tech Stack

- **Frontend:** React 19  
- **Build Tool:** Vite  
- **Styling:** TailwindCSS  
- **Icons:** Lucide React  
- **AI Integration:** Google Generative AI (`@google/genai`)  
- **Language:** TypeScript
